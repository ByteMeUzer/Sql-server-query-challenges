# 🗄️ SQL Server Query Challenges

A curated collection of advanced T-SQL solutions built on 5+ years of hands-on experience in database development, query optimization and data analysis with Microsoft SQL Server.

## 🎯 What This Repository Covers

- **Window Functions**: RANK, DENSE_RANK, ROW_NUMBER, LAG/LEAD, running totals
- **CTEs**: standard and recursive (hierarchies, date and number series)
- **Joins**: self joins, anti joins, complex multi-table joins
- **Performance Tuning**: execution plan analysis, indexing strategy, set-based vs row-based approach
- **Programmability**: stored procedures, views, triggers, error handling (TRY/CATCH)
- **Data Transformation**: PIVOT/UNPIVOT, dynamic SQL, data cleansing

## 🛠️ Tech Stack

- Microsoft SQL Server (T-SQL)
- SSMS

## 💡 Highlights

- Real-world business scenarios (sales analysis, employee hierarchy, deduplication)
- Optimized, readable and production-ready queries
- Each solution includes the problem statement and approach
